## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Install as an app

The production build generates the service worker and serves the web app manifest and app icons. Deploy the site over HTTPS (or use `localhost` while developing) to enable installation.

- **Windows:** Open the deployed site in Microsoft Edge or Chrome and select the install icon in the address bar, or use the browser menu's **Install Ghar Ka Zaiqa** option.
- **Android:** Open the site in Chrome and tap **Install app** when it appears, or choose **Install app** / **Add to Home screen** from the browser menu.

Run `npm run build` before deployment so the PWA service worker is generated. The worker is disabled during development.
